🛡️ Windows 안전 설치 가이드

처음 설치할 때 파란 경고가
나오면 어떻게 하나요?

당황하지 마세요. 새로 출시된 한국 앱은 처음에 거의 모두 이 화면을 만납니다.
안전한 앱이고, 3초면 통과할 수 있어요.

💡 짧게 요약하면

Windows 가 "이 앱을 처음 봐서 안전한지 아직 확인 못 했어요" 라고 보호 경고를 띄우는 거예요. 부비서 데스크톱은 한국 정식 사업자(주식회사 부비서)가 만든 안전한 앱입니다. 아래 4단계로 진행하시면 됩니다 — 한 번 통과하면 다음부터는 경고가 나오지 않아요.

1

설치 파일(.exe) 다운로드

홈페이지의 Windows 다운로드 버튼을 클릭하면 Bubiseo-Setup-X.X.X.exe 파일이 받아져요. 다운로드 폴더에서 파일을 더블클릭하면 설치가 시작됩니다.

2

"Windows의 PC 보호" 모달이 나타나요

파란색 모달이 나오는데요, 이 화면이에요:

Windows의 PC 보호
Microsoft Defender SmartScreen이 인식할 수 없는 앱의 시작을 중지했습니다. 이 앱을 실행하면 PC가 위험에 노출될 수 있습니다.
앱: Bubiseo-Setup-1.2.7.exe

여기서 바로 실행 안 함을 누르지 마시고, 왼쪽 위의 자세히 또는 추가 정보 글자를 클릭해주세요.

3

"추가 정보" 클릭 → "실행" 버튼이 나타나요

글자를 클릭하면 모달이 펼쳐지면서 앱 정보 + "실행" 버튼이 나타나요.

Windows의 PC 보호
Microsoft Defender SmartScreen이 인식할 수 없는 앱의 시작을 중지했습니다.
앱: Bubiseo-Setup-1.2.7.exe
게시자: 알 수 없는 게시자

"실행" 버튼을 클릭하시면 설치 마법사가 시작됩니다.

4

설치 마법사 진행 → 완료

이제부터는 일반 Windows 앱 설치와 동일해요. "다음" → "동의" → "설치" 순서로 진행하시면 됩니다. 설치가 끝나면 바탕화면과 시작 메뉴에 부비서 아이콘이 자동으로 만들어져요.

✓ 다음부터는 SmartScreen 경고가 안 나옵니다. 처음 한 번만 이 과정이 필요해요.

자주 묻는 질문

왜 경고가 뜨나요? 안전하지 않은 앱인가요?

전혀 그렇지 않습니다. Microsoft 의 SmartScreen 은 "이 앱을 다운로드한 사람이 아직 많지 않다"는 신호만 보고 일단 보호 경고를 띄워요. 안전성을 의심해서가 아니라, 신규 출시 앱이라는 의미입니다. 부비서 데스크톱은 한국 정식 사업자(주식회사 부비서, admin@bubiseo.com) 가 만들었고, 공인중개사 사무소에서 매일 사용 중인 안전한 앱입니다.

바이러스나 악성코드는 절대 없나요?

네. 설치 파일은 GitHub 공개 저장소(bubiseo-admin/bubiseo-desktop-releases) 에서 직접 빌드되어 배포됩니다. 누구나 빌드 이력 + 파일 해시(SHA-256) 를 확인할 수 있어요. 의심되시면 VirusTotal 같은 무료 서비스에 파일을 올려서 50여 개 백신 엔진으로 한 번에 검사해 보실 수도 있습니다.

이 경고를 안 나오게 할 수는 없나요?

코드 사이닝 인증서(Code Signing Certificate) 라는 걸 도입하면 경고가 사라집니다. 저희는 곧 Microsoft Store 등록 + EV 코드 사이닝 인증서 도입을 준비 중이에요. 적용이 완료되면 첫 설치부터 경고 없이 부드럽게 진행됩니다.

설치 후 자동 업데이트는 어떻게 되나요?

설치 한 번이면 다음 버전부터는 자동으로 업데이트돼요. 부비서를 종료(⌘Q 또는 X 닫기)한 다음 다시 실행하시면 새 버전이 자동 적용됩니다. 이때는 SmartScreen 경고도 다시 나오지 않습니다.

설치 중 막히거나 다른 오류가 나면 어떻게 하나요?

admin@bubiseo.com 으로 메일 보내주세요. 화면 캡처를 첨부해 주시면 더 빨리 도와드릴 수 있어요. 평일 영업시간 안에는 대부분 30분 안에 회신드립니다.

이제 안전하게 시작해볼까요?

위 안내를 참고하시면 3분 안에 설치가 끝납니다.
